# Loan-eligibility
A java loan eligibility  project checking conditions necessary to qualify for a zenka loan
The projects checks the following conditions age,salary,nationality,employment status and loan amount to be borrowed.
If age<27,
Salary<100000,
not employed,
!nationality.equalsIgnorecase Kenyan or
loan amount>500000 &salary<800000 
one doesn't qualify.
Else one is eligible for zenka loan.
